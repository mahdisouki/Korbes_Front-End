# Station thermale de Korbous

Independent presentation site for the Korbous thermal station in Tunisia. Frontend only: no booking, payment, or server.

## Run

```bash
npm install
npm run dev
```

French is the default language. The language menu also offers Arabic (right-to-left), English, Polish, Spanish, German, and Russian.

Hours, prices, testimonials, and the contact form are marked as demonstration content. The form validates in the browser and does not send a message.
